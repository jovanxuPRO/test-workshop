# PRD-B001：搜索核心功能模块

## 版本历史
| 版本 | 日期 | 作者 | 变更说明 |
|------|------|------|----------|
| v1.0 | 2026-01-20 | 产品部 | 初稿 |

## 1. 业务背景
搜索是百度最核心的功能。用户在首页搜索框输入关键词，系统返回相关性排序的结果列表。本 PRD 覆盖搜索请求处理、结果返回、分页浏览三大环节。

## 2. 核心流程
```
输入关键词 → 发起搜索请求 → 服务端检索+排序 → 返回结果页 → 用户翻页浏览
```

## 3. 功能需求

### 3.1 搜索请求
- 关键词通过 `wd` 参数传递（GET /s?wd=xxx）
- 支持中英文、数字、特殊符号关键词
- 空关键词请求应返回首页或提示，不应报错

### 3.2 搜索结果
- 结果按相关性排序，最相关的内容排最前
- 每页默认 10 条结果
- 支持 `rn` 参数控制每页条数（如 rn=50）
- 支持 `pn` 参数翻页（pn=10 表示第 2 页）

### 3.3 分页
- 结果超过一页时显示翻页导航
- 翻页不应改变已确定的关键词

## 4. 业务规则

| 编号 | 规则 | 严重级别 |
|------|------|----------|
| R001 | 搜索请求必须返回 HTTP 200（含重定向到结果页） | 严重 |
| R002 | 结果页 HTML 必须包含搜索结果列表容器 | 严重 |
| R003 | 空关键词请求不应导致 5xx 错误 | 严重 |
| R004 | 翻页请求（pn>0）必须正常返回 | 严重 |
| R005 | 每页条数参数 rn 超出上限时服务端应限制 | 重要 |
| R006 | 特殊字符关键词（<script>、' OR 1=1）不应破坏页面 | 严重 |
| R007 | 中文关键词必须正常处理（UTF-8 编码） | 严重 |
| R008 | 搜索响应时间 P95 < 3 秒 | 重要 |

## 5. 边界与异常场景

### 5.1 空关键词
- 场景：GET /s?wd=
- 预期：返回 200，显示首页或搜索引导，无 5xx

### 5.2 超长关键词
- 场景：wd=5000 个字符
- 预期：服务端截断或正常返回，不应内存溢出

### 5.3 XSS 注入
- 场景：wd=<script>alert(1)</script>
- 预期：页面不应执行注入脚本，结果页正常渲染

### 5.4 SQL 注入
- 场景：wd=' OR '1'='1
- 预期：按普通文本处理，不应返回异常数据

### 5.5 翻页越界
- 场景：pn=99999（远超结果总页数）
- 预期：返回空结果页或最后一页，不应 500

## 6. 非功能性需求
- 搜索首页加载时间 < 5 秒（P95）
- 并发 50 QPS 下搜索服务稳定
- 移动端（375px）搜索结果正常显示
