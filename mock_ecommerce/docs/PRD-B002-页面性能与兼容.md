# PRD-B002：页面性能与多端兼容模块

## 版本历史
| 版本 | 日期 | 作者 | 变更说明 |
|------|------|------|----------|
| v1.0 | 2026-01-20 | 产品部 | 初稿 |

## 1. 业务背景
百度首页和结果页面向海量用户，覆盖 PC 端和移动端浏览器。页面加载速度直接影响用户体验和留存率。本 PRD 定义页面性能指标和兼容性要求。

## 2. 功能需求

### 2.1 页面加载
- 首页首屏渲染时间 < 5 秒（弱网 4G 环境）
- 页面必须包含搜索框（input 元素）
- Logo 图片必须成功加载（无 404/403）

### 2.2 静态资源
- 所有 CSS/JS/图片资源必须成功加载
- 页面不允许出现 4xx/5xx 资源错误
- 浏览器 Console 不允许出现 JS 报错

### 2.3 多端适配
- PC 端（1280x720 及以上）完整布局
- 平板端（768x1024）自适应布局
- 移动端（375x812）单列布局，无横向滚动

### 2.4 协议支持
- 支持 HTTP/1.1 与 HTTP/2
- HTTPS 必须有效（证书合法）
- 应正确跟随重定向（301/302）

## 3. 业务规则

| 编号 | 规则 | 严重级别 |
|------|------|----------|
| R101 | 首页加载时间 < 5 秒 | 严重 |
| R102 | Logo 图片必须可访问（200） | 严重 |
| R103 | 页面不允许有 JS 控制台错误 | 严重 |
| R104 | 页面必须包含至少 1 个导航链接 | 重要 |
| R105 | 移动端 375px 视口下页面正常渲染 | 严重 |
| R106 | 所有静态资源响应码 < 400 | 严重 |
| R107 | 响应头包含 Content-Type 与内容编码声明 | 重要 |
| R108 | 并发 10 请求下首页仍稳定响应 | 重要 |

## 4. 边界与异常场景

### 4.1 弱网环境
- 场景：网络延迟 500ms
- 预期：页面在 5 秒内完成首屏渲染

### 4.2 极窄视口
- 场景：视口宽度 320px（小屏手机）
- 预期：无横向滚动条，内容正常可读

### 4.3 图片加载失败
- 场景：某图片 URL 返回 404
- 预期：不影响页面整体功能（搜索框仍可用）

### 4.4 重定向链
- 场景：http:// 请求被重定向到 https://
- 预期：客户端正确跟随，最终 200

## 5. 性能基准

| 指标 | 目标 |
|------|------|
| 首屏时间 | P50 < 2s, P95 < 5s |
| 资源加载 | 全部 < 400 状态码 |
| 并发稳定性 | 10 并发无 5xx |
| JS 错误 | 0 个 pageerror |
