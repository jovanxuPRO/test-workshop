# PRD-B003：搜索安全与内容规范模块

## 版本历史
| 版本 | 日期 | 作者 | 变更说明 |
|------|------|------|----------|
| v1.0 | 2026-01-20 | 产品部 | 初稿 |

## 1. 业务背景
搜索引擎接收任意用户输入，恶意输入（XSS、SQL 注入、超长文本）可能破坏页面或窃取数据。本 PRD 定义搜索输入的安全处理规范和内容过滤要求。

## 2. 功能需求

### 2.1 输入安全处理
- 所有搜索关键词必须做 HTML 转义，结果页不得原样输出未转义的用户输入
- SQL 注入字符按普通文本处理
- 控制字符（\x00-\x1f）应被过滤或转义

### 2.2 请求方法规范
- 搜索请求以 GET 为主
- POST /s 也需支持（表单提交场景）
- 非法的请求方法（如 PUT）应被拒绝或降级

### 2.3 建议功能
- `rsv_spt=1` 参数启用搜索建议
- 建议接口必须快速响应（< 1 秒）

## 3. 业务规则

| 编号 | 规则 | 严重级别 |
|------|------|----------|
| R201 | 搜索结果页不得执行用户注入的 <script> | 严重 |
| R202 | SQL 注入关键词按普通文本处理 | 严重 |
| R203 | 超长关键词（>5000 字符）不应导致服务崩溃 | 严重 |
| R204 | 搜索建议接口（rsv_spt=1）正常返回 | 重要 |
| R205 | 错误页面（/search/error.html）可正常访问 | 一般 |
| R206 | 敏感内容关键词应被内容安全策略过滤 | 重要 |
| R207 | 搜索请求不允许导致服务端内存泄漏 | 严重 |

## 4. 边界与异常场景

### 4.1 XSS 注入
- 场景：wd=<script>alert(document.cookie)</script>
- 预期：页面正常渲染，脚本不执行，或请求被拒绝（400）

### 4.2 SQL 注入
- 场景：wd=1' OR '1'='1' --
- 预期：返回正常搜索结果（无匹配内容），不泄露数据库信息

### 4.3 超长输入
- 场景：wd=10000 个 "a"
- 预期：服务端截断或拒绝，不崩溃，响应时间不异常增长

### 4.4 空字节注入
- 场景：wd=%00%00
- 预期：安全处理，不影响正常搜索

### 4.5 Unicode 混淆
- 场景：wd=ＡＢＣ（全角字符）
- 预期：正常处理为普通文本搜索

## 5. 安全检测清单

| 检测项 | 方法 | 预期 |
|--------|------|------|
| 反射型 XSS | 注入 <script> 看是否回显 | 不回显或转义 |
| SQL 注入 | 注入 ' OR 1=1 看返回 | 正常空结果 |
| 命令注入 | 注入 ; ls 看是否执行 | 不执行 |
| 路径遍历 | ../../etc/passwd | 不泄露文件 |
| 超长输入 | 10000 字符 | 不崩溃 |
